# Task 1 - Cuisine Combination Analysis

## Objective
To identify the most common cuisine combinations
and determine whether certain combinations have
higher ratings.

## Dataset
Restaurant dataset containing restaurant names,
cities, cuisines, ratings, votes, price range,
and online delivery information.

## Analysis
- Identified cuisine combinations
- Found the most common combinations
- Calculated average ratings
- Identified highly-rated combinations
- Created visualizations

## Conclusion
The analysis shows the most common cuisine
combinations and compares their average ratings
to identify highly-rated combinations.
